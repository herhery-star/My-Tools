⚙️ Pengaturan Google Drive

Gunakan satu project Google Cloud untuk Drive API dan Picker. v0.6 memakai scope drive.file agar akses Drive dibatasi per file. Client Secret tidak dimasukkan ke HTML.

Scope v0.6: https://www.googleapis.com/auth/drive.file — akses dibatasi pada file yang dipilih/digunakan aplikasi. Di Google Cloud, tambahkan scope ini di Data Access → Add or remove scopes.

GitHub Pages: Authorized JavaScript origin: https://herhery-star.github.io. Untuk lokal: http://localhost:8000. Jangan masukkan Client Secret.
